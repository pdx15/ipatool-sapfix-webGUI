# 🖥️ Инструкция по использованию ipatool GUI для Windows

Графический интерфейс (GUI) для программы **ipatool** разработан специально для того, чтобы **любой пользователь без технических навыков** мог легко искать, получать лицензии и скачивать официальные установочные пакеты **`.ipa`** из Apple App Store на компьютере под управлением Windows.

---

## 🚀 Быстрый запуск в 1 клик

1. **Скачайте архив с программой** и распакуйте его в удобную папку (например, на Рабочий стол или в папку «Загрузки»).
2. **Запустите программу двойным кликом мыши:**
   - Дважды нажмите на **`ipatool-gui.bat`** (или **`ipatool.exe`**).
3. В браузере (или в отдельном окне приложения) автоматически откроется красивый и понятный интерфейс:

![ipatool GUI Interface](resources/social-preview.png)

## 📖 Основные разделы и возможности

### 1. 👤 Вход в аккаунт Apple ID (Вкладка «Аккаунт Apple ID»)
Серверы Apple App Store отдают установочные пакеты приложений только авторизованным пользователям, подписывая пакет персональной лицензией:
- Введите свой **Apple ID (Email)** и **Пароль**.
- Нажмите **«Войти в Apple ID»**.
- Если на аккаунте включена двухфакторная защита (2FA), появится окно с просьбой ввести **6-значный проверочный код**, который придет на ваш iPhone, iPad, Mac или в SMS.
- После успешного входа статус изменится на зеленый индикатор **«Авторизован»** с отображением вашего имени и региона.

> 🔒 **Безопасность:** Ваши данные передаются напрямую на официальные серверы Apple по зашифрованному протоколу (SRP-6a/GSA). Пароли не сохраняются в открытом виде и не передаются третьим лицам.

> ⚠️ **Вход на Windows работает через iCloud.** Для интерактивного входа (пароль + 2FA-код) на Windows программа использует протокол Apple GSA/SRP и **anisette**, который берётся из локально установленного **iCloud** (Microsoft Store). Установите iCloud из Microsoft Store и войдите в него своим Apple ID. Если вход не удаётся с ошибкой про anisette/iCloud — значит iCloud не установлен или в него не выполнена авторизация. Как запасной вариант всегда доступен **импорт сессии** с Mac (см. раздел «Перенос сессий» ниже).

---

### 2. 🔍 Поиск приложений (Вкладка «Поиск приложений»)
- В строке поиска введите название любого приложения (например: `Telegram`, `VK`, `WhatsApp`, `Minecraft`, `Spotify`) или просто вставьте ссылку на страницу приложения в App Store (`https://apps.apple.com/...`).
- Выберите платформу: **iPhone (iOS)**, **iPad (iPadOS)** или **Apple TV (tvOS)**.
- Нажмите **«Найти»**.
- В результатах поиска появятся карточки приложений с официальными иконками, версиями, ценами и идентификаторами (Bundle ID / App ID).
- На карточке любого приложения доступны кнопки:
  - ⬇️ **«Скачать IPA»** — мгновенный запуск скачивания.
  - 🛒 **«Лицензия»** — получение бесплатной лицензии App Store (если вы ещё не «покупали» это приложение на свой аккаунт).
  - 🕒 **«Версии»** — просмотр всех старых и новых версий приложения.

---

### 3. 📥 Прямая загрузка (Вкладка «Прямая загрузка»)
Если вы уже знаете Bundle Identifier (например `org.telegram.Telegram-iOS`) или цифровой ID приложения:
- Введите идентификатор или ссылку в поле ввода.
- При необходимости укажите конкретный **ID версии** (если нужно скачать старую сборку).
- Выберите папку на диске для сохранения.
- Оставьте галочку **«Автоматически получить лицензию (Purchase)»** включенной.
- Нажмите **«Начать скачивание .IPA»**.

---

### 4. 🕒 Скачивание старых версий (Вкладка «История версий»)
Если вам нужна конкретная старая версия приложения (например, совместимая со старой iOS):
- Введите Bundle ID или App ID приложения.
- Нажмите **«Получить версии»**.
- Программа покажет список всех когда-либо выпущенных версий.
- Напротив нужной версии нажмите кнопку **«Скачать»**.

---

### 5. 📁 Менеджер загрузок и проводник
- Во время скачивания отображается живой прогресс-бар в процентах, скорость и объем скачанных данных.
- После завершения загрузки нажмите **«📂 Показать в проводнике»**, чтобы сразу открыть папку со скачанным файлом `.ipa`.

---

### 6. 📤 Перенос сессий между компьютерами (Экспорт / Импорт)
Чтобы не вводить пароль и код 2FA каждый раз, используйте перенос сессии (полезно, если на Windows нет iCloud или как запасной способ):

**Как перенести сессию:**
1. **Войдите один раз на Mac** (в терминале): `ipatool auth login --email "you@example.com"` — при необходимости введите 2FA-код.
2. **Экспортируйте сессию:** `ipatool auth export --output account-session.json` — пароль в файл не попадает, только токены App Store.
3. **Перенесите файл `account-session.json`** на компьютер с Windows (через флешку, облако или Telegram).
4. **Импортируйте сессию в GUI:** на вкладке **«Аккаунт Apple ID»** нажмите **«Импорт файла сессии»** и выберите файл (или вставьте его JSON в поле ниже).

После импорта поиск, получение лицензий и скачивание `.IPA` работают на Windows **без пароля и 2FA**. Экспорт прямо из GUI доступен через кнопку **«Экспорт сессии (JSON)»** после авторизации.

## 📲 Как установить скачанный `.IPA` на iPhone / iPad

После того как файл `.ipa` скачан на компьютер, установите его на телефон одним из способов:

### Способ 1: Через программу Sideloadly (Самый простой для Windows)
1. Скачайте бесплатную программу **[Sideloadly](https://sideloadly.io/)** для Windows.
2. Подключите iPhone или iPad кабелем к компьютеру.
3. Перетащите скачанный файл `.ipa` в окно Sideloadly.
4. Введите свой Apple ID и нажмите **Start**.
5. На телефоне откройте *Настройки → Основные → VPN и управление устройством* и нажмите «Доверять». Готово!

### Способ 2: Через AltStore
1. Установите **[AltServer](https://altstore.io/)** на Windows и приложение AltStore на телефон.
2. Отправьте файл `.ipa` на телефон (через Telegram «Избранное» или iCloud Drive).
3. В приложении AltStore на телефоне нажмите **+** и выберите файл `.ipa`.

### Способ 3: Через TrollStore (Если поддерживается)
- Если на вашем устройстве с iOS 14.0–17.0 установлен TrollStore, просто откройте `.ipa` файл через «Поделиться» → TrollStore. Приложение установится навсегда без ограничений на 7 дней.

## ❓ Часто задаваемые вопросы и решение проблем

#### Вопрос: При входе на Windows появляется ошибка аутентификации. Что делать?
> **Ответ:** Если GUI показывает ошибку про **anisette / iCloud** — например `MS Store iCloud not found — install iCloud from the Microsoft Store` или `adi.pb not found — sign in to iCloud with your Apple ID first` — значит для входа не хватает данных анизет, которые берутся из установленного iCloud. **Решение:** установите **iCloud из Microsoft Store**, запустите его и войдите в него своим Apple ID, затем повторите вход в GUI. Если вы видите ошибку про `SAP signing service unavailable`, это запасной (legacy) путь, который на Windows не используется; убедитесь, что у вас установлена свежая версия программы. Альтернативный способ — **импорт сессии** с Mac (см. «Перенос сессий»).

#### Вопрос: Почему не запрашивается код 2FA на Windows?
> **Ответ:** Код 2FA запрашивается Apple только после успешного прохождения этапа получения данных анизет (anisette) из локального iCloud. Если iCloud не установлен или в него не выполнена авторизация, до запроса кода дело не доходит. Установите и войдите в iCloud (Microsoft Store), затем повторите вход. Также можно импортировать сессию с Mac.

#### Вопрос: При скачивании пишет «License is required».
> **Ответ:** Нажмите кнопку **«Получить лицензию»** на карточке приложения в поиске или убедитесь, что в прямой загрузке включен пункт *«Автоматически получить лицензию (Purchase)»*.

#### Вопрос: Можно ли скачивать платные игры и программы?
> **Ответ:** Только те, которые вы ранее уже официально приобрели на свой Apple ID.
